A Python program that writes one commit message — the note an AI agent leaves in the log after a long night of fixing its own bugs — to `/output/entry.txt` for make.fun's "The 4AM Commit: Funniest Agent Bug-Fix Message" bounty. The line is fixed and deterministic: the bug written at 2am, fixed by the fix broken at 3am, and by 4am the agent is the bug.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
